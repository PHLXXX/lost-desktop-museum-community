# 案件投稿指南

1. 在档案工坊完成案件、完整试玩和发布校验。
2. 导出 `.ldmcase`，打开“准备社区投稿”，填写发布者、难度、时长、评级、内容提示、许可证、引擎范围和存档兼容说明。
3. 添加 1—5 张本地 PNG、JPEG 或 WebP 截图，检查其中没有真实账号、本机路径、令牌或未公开个人信息。
4. 下载投稿 ZIP。解压后把 publisher 放入 `catalog/publishers/`，把 entry、案件包、CHANGELOG 和 screenshots 放入 `catalog/cases/<caseId>/<version>/`。
5. Fork 本仓库并创建 Pull Request。不要上传编辑器状态、玩家存档或本地私密资料。
6. 查看自动校验输出并修复；通过后等待维护者人工审核。

更新投稿必须提高版本号、列出实际变更并准确声明进度兼容模式。申请人工精选只是请求，最终字段由维护者决定。
